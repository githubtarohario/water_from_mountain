本書について

本書のねらい

本書は、1 本の完結したプログラム「山から粒子が落ちる」を教材として、3D コンピュータグラフィックス（CG）と粒子法による流体シミュレーションを基礎から解説する教科書です。このプログラムは、岩肌の山に刻まれた谷を水の粒子が流れ落ち、粒子の集まりから水面を生成して描画します。見た目はシンプルですが、その中には CG と物理シミュレーションの主要な技術がひととおり詰まっています。

  • 座標系・ベクトル・行列と、3D をスクリーンに映すまでの変換の数学
  • GPU が絵を作る手順（レンダリングパイプライン）と DirectX 11 の使い方
  • GPU 上で動く小さなプログラム、シェーダー（HLSL）
  • 光と影、テクスチャによる質感表現
  • ノイズによる地形・テクスチャの手続き的生成、外部モデルの取り込み
  • 粒子で水を表す SPH 法と、それを速く安定に動かす工夫
  • 粒子の集まりを 1 枚の水面として見せるスクリーンスペース流体レンダリング

各技術は「なぜ必要か → 考え方 → 数式 → 実際のコード」の順に説明します。掲載しているコードは本書の生成時にソースファイルから自動的に抜き出しており、リポジトリの実装と一致しています。

想定する読者

C++ の基本文法（クラス、参照、STL の vector）が読めること、高校数学（三角関数、ベクトル）を一度は学んだことを前提にします。行列や微分は必要になった箇所で説明します。DirectX やシェーダーの経験は不要です。

プログラムの入手と実行

リポジトリhttps://github.com/githubtarohario/water_from_mountain
必要環境Windows 10/11、DirectX 11 対応 GPU、Visual Studio 2019/2022（C++ デスクトップ開発）
ビルドMountainParticles.sln を Release | x64 でビルド、または build.bat
操作左ドラッグ: 回転 / 右ドラッグ: 移動 / ホイール: ズーム / 1: 粒子表示 / 2: 表面生成 / Space: 一時停止 / R: リセット
粒子表示モード（速度で青→緑→赤に着色）
表面生成モード（粒子から水面を作って描画）

本書の記法

  • ベクトルは太字（v）、スカラーは斜体（x）、行列は大文字斜体（M）で表します。
  • コードの引用は緑の枠で、その上にファイル名を示します。
  • ポイント は必ず押さえてほしい要点、注意 は間違えやすい点、コラム は補足の読み物です。
  • 各章末の演習は、プログラムを改造して理解を確かめる課題です。
